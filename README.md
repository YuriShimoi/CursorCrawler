# Cursor Crawler
A mouse-driven roguelike dungeon crawler for the browser.

**[Play the demo](https://yurishimoi.github.io/CursorCrawler/)**

Docs (⚠️ spoilers: they show every enemy, boss and mechanic of the game):
- [Style reference](https://yurishimoi.github.io/CursorCrawler/docs/style.html): colors, sprites, UI and sounds
- [Test arena](https://yurishimoi.github.io/CursorCrawler/docs/arena.html): fight any enemy or boss on any floor

Sounds are CC0 (see `assets/sounds/CREDITS.md`).
